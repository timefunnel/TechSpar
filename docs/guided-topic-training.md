# 专项带教训练第一版

专项训练保留原有整轮考核，新增「带教学新知识」「到期复习」「错题回顾」。

## 学习流程

- 新知识每组 4 题，同一知识点依次练习判断纠错、选择解释、代码找错、场景问答。
- 不会时可选择「忘了」「概念没懂」「懂但说不清」，获得两层提示或查看讲解。
- 回答后即时展示正确部分、遗漏点、错误理解、30 秒核心答法和展开讲解。
- 隐藏参考答案后可复述一次；立即生成的变式题只用于巩固。每轮最多 8 题。
- 至少尝试一题才能结束；未回答题不计为答对。已提交回答、提示、讲解、复述和变式可刷新续练，未提交输入不会自动保存。
- 错题按领域和知识点归并，保留最近的低分／辅助回答及其原题和遗漏。一次独立答对不会擦掉原错题；历史记录仍保留每道题的完整证据。
- 旧考核中低于 8 分的题也可回顾，辅助使用情况标记为「历史未知」，不推测为独立作答。

## 掌握与间隔复习

- 8/10 为本题答对阈值；仅选择选项或仅判断，没有解释，最多 4 分。
- 独立答对与提示／讲解／反馈后答对分别记录。服务器保存辅助使用时间，多轮打开时也检查当日同知识点暴露。
- 判断、选择、复述、同日变式和辅助答对都不会提高画像中的独立应用掌握度。
- 复用现有画像 `weak_points[].sr` 和 `sm2Update`。辅助练习或低分使用不超过 4 分的调度分，回到次日复习；真实练习分保持原样。
- 无提示代码／场景作答才是独立应用证据。同知识点在不同 UTC 日期连续两次独立应用达到 8 分，才标记改善；独立通过会按现有算法逐步延长间隔。
- 已改善的带教知识点仍保留到期复习，避免改善后永久退出记忆计划。归档的薄弱点不被旧错题重新拉回。
- 日期沿用已有 UTC 日历，不是按作答后精确 24 小时计时；这一版不发送定时通知。

上述独立应用证据规则适用于新增带教训练；原有整轮考核继续使用既有画像评分流程。

## 数据与失败语义

学习状态保存在现有会话 `meta.drill_learning`，没有新增独立错题库或客户端复习计划。历史列表需要的对话是同一事务中的兼容投影；复习日期和改善状态以画像为准。

回答先持久化，再用尝试 ID 幂等更新画像。画像同步失败明确返回 503，重新加载恢复同步，不重新调用模型评分。旧的延迟尝试可保留证据，但不能覆盖更新的复习计划。并发修改使用 revision 校验，冲突返回 409，不静默覆盖。

无可检索参考资料返回 422；模型 JSON、题型或评分无效返回 502，不伪造题目／评价。带教记录不能通过旧考核接口重评或获取未记录的讲解。

新增 API：`GET /api/drill/queue`、`POST /api/drill/start`、`GET /api/drill/session/{id}`、`POST .../action`、`POST .../finish`。所有接口验证登录及用户归属，请求和响应复用共享契约。

## 本地验证

运行 `bun test tests-ts/drill-learning.test.ts`、`bun run test:web`、两端类型检查、`typecheck:node`、`check:boundaries`、`gen:api`、`build:api` 和 `build:web`。

浏览器验收使用隔离临时数据库、合成账户及合成模型输出，检查输入、提示、反馈、隐藏答案复述、刷新、变式、错题和手机布局。不连接生产数据；合成输出不能证明真实模型的出题与反馈质量，发布前需用实际配置做小样本验收。

## 简历定制题库

入口：专项训练 → 简历定制题库。选择本账号浏览器简历库中的文本版本，生成 1-12 个带原文依据的考点；可取消考点，再确认保存。清单保存于现有 `prepared` 会话的 `meta.resume_drill_plan`，页面展示最近 20 份，历史记录也可打开清单。没有新增简历数据库或并行错题库。

- 复用编辑器的可见段落序列化，排除基本联系方式、照片与证书图片；第一版不混用服务器 PDF。正文 40-20000 字，不截断后假装使用完整简历。
- 每个考点必须关联当前版本中确实出现的项目／工作名称和连续原文摘录。模型改写摘录、虚构关联项目、返回未知领域或重复考点都拒绝保存。
- 确认时验证选中版本、内容和 revision；浏览器还校验同账号的已保存内容，其他窗口修改、删除或账号切换后不能确认过期预览。已确认清单不可重写；后续修改简历需生成新清单。开始训练明确使用确认时快照。
- 每个考点按需生成三类训练：「补原理」4 题、「项目应用」场景＋代码 2 题、「成果追问」场景 2 题。用户确认考点后才调用模型出题，并非提前一次生成全部题目。
- 所有题目保存版本名、关联项目、原文依据、待确认事项和阶段。变式、复述、刷新和到期／错题复习保留同一题的来源，逐题使用对应依据，不混用多个项目。
- 项目应用中新增约束是假设，不声称是候选人的实际实现；缺失时间、架构、个人职责与成果指标的基线／统计口径须本人补充。原文中的业务金额不推导为 QPS，简历声称也不等于已核实成果。
- 技术与项目表达分别计分；表达尝试复用画像的 `axis=performance` 薄弱点及同一 SM-2 调度，接入带教错题／到期回顾，但不更新技术掌握度。结束回顾中 `avg_score` 仅计算技术练习，`project_expression_avg_score` 单独计算表达，纯表达训练的技术分为 `null`。提示后答对仍算辅助；同日巩固不延长独立复习间隔。
- 技术训练仍必须有题库参考资料；表达训练只核验表达结构与简历证据，不依赖技术资料，也不评判未提供的技术实现。
- 删除原始表达训练记录后，若复习项已无法关联简历依据，明确要求从简历定制题库重新开始；不会把表达复习静默降级为技术题或提高技术掌握度。

API：`GET /api/drill/resume/plans`、`GET /api/drill/resume/plan/{id}`、`POST /api/drill/resume/preview`、`POST /api/drill/resume/plan/{id}/confirm`、`POST /api/drill/resume/start`。全部验证用户归属及共享输入／输出契约。预览或出题失败显示真实错误，不静默回退到通用题库；已保存清单可重新加载，较早的清单可通过历史记录直接打开。

## 讲解右键快捷答疑

完成作答或主动查看讲解后，可在当前题已经展示的讲解／反馈中选中文本，右键打开「快捷答疑」侧栏。侧栏默认解释选中概念，并提供参数区别、结合当前题、面试追问与自由追问；切题时关闭，桌面端不离开训练工作台。

- 服务端只接受当前题已展示内容中的 2-500 字选区，绑定账号、会话、revision 与 question ID；答题前的题干、任意拼接文本和过期状态都会被拒绝。
- 回答同时使用当前题、考点、已展示反馈与该领域学习资料；资料缺失显式报错，不回退为无依据回答。简历题仅附带当前题已经绑定的项目原文，不读取其他简历版本。
- 快捷答疑不修改训练 revision、作答、评分、掌握度或间隔复习；它是当前反馈后的学习辅助，不作为独立答对证据。
- 接口：`POST /api/drill/session/{session_id}/quick-answer`。自定义追问上限 1000 字，返回 Markdown 上限 12000 字；输入输出均经过共享契约验证。
